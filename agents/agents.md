# Agent Workflow

## Task Management Workflow

1. **Pick tasks from `to-do.md`**
   - Select a task with status "Pending"
   - Update status to "In Progress" in `to-do.md`

2. **Complete the task**
   - Implement the required changes
   - Test the implementation
   - Update code as needed

3. **Move task to `done.md`**
   - Copy the completed task from `to-do.md` to `done.md`
   - Add completion date and any notes
   - Remove the task from `to-do.md`
   - Update status to "Completed"

## Task Status Values
- **Pending**: Task not started
- **In Progress**: Task currently being worked on
- **Completed**: Task finished (moved to `done.md`)
