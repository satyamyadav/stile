# Agents Directory

This directory contains agent-related documentation and task management files.

## Purpose

The agents directory is used for:
- Task management workflows
- Agent instructions and guidelines
- Task tracking and completion status

## Files

- `agents.md` - Agent workflow instructions
- `to-do.md` - Current tasks to be completed
- `done.md` - Completed tasks archive
- `TRD.md` - Technical Requirements Document
